Validar y leer XML

Detectar errores antes de enviar ahorra correlativos rechazados. La librería tiene dos niveles de validación, además de herramientas para leer XML existentes.

1. Validar el modelo

Revisa campos obligatorios, formatos (RUC, series, códigos de catálogo) y estructura, igual que Greenter:

import { SymfonyValidator, XmlErrorCodeProvider } from '@jeanpierohc/sunat-manager';

const validator = new SymfonyValidator(new XmlErrorCodeProvider());
validator.setVersion('2.1');

const errores = [...validator.validate(factura)];
if (errores.length) {
  for (const e of errores) console.log(e.getPropertyPath(), '→', e.getMessage());
  // company.ruc → This value is not valid.
  // details[0].unidad → This value should not be blank.
}

Los mensajes son los de Symfony Validator (en inglés); getPropertyPath() indica exactamente qué campo revisar.

2. Validar el XML con las reglas de SUNAT

SUNAT publica sus reglas de validación como hojas XSL. Con ellas obtienes el mismo código de error que daría SUNAT, sin enviar nada. Requiere el paquete opcional saxon-js y las hojas XSL oficiales (descárgalas del portal de SUNAT y ordénalas en carpetas 1.X / 2.X):

npm install saxon-js
import { CpeValidator } from '@jeanpierohc/sunat-manager';

const validator = CpeValidator.create('./xsl');            // carpeta con 1.X y 2.X
const errores = validator.validateFromXml(`${factura.getName()}.xml`, xmlFirmado);

for (const e of errores) {
  console.log(e.getCode(), e.getMessage(), e.getLevel() === '2' ? '(observación)' : '(error)');
}

Mensajes de error de SUNAT en español

XmlErrorCodeProvider contiene el catálogo oficial (más de 1 700 códigos):

import { XmlErrorCodeProvider } from '@jeanpierohc/sunat-manager';

const codes = new XmlErrorCodeProvider();
codes.getValue('2017');   // 'El numero de documento de identidad del receptor debe ser  RUC'
codes.getAll();           // Map con los 1 710 códigos

see.setCodeProvider(codes);   // los errores de see.send() traen el mensaje en español

Leer XML existentes

Convierte un XML (tuyo o de un proveedor) de vuelta en modelo, para mostrarlo, reimprimirlo o registrarlo:

import fs from 'node:fs';
import { InvoiceParser, HtmlReport } from '@jeanpierohc/sunat-manager';

const factura = new InvoiceParser().parse(fs.readFileSync('20000000001-01-F001-15.xml'));
factura.getClient().getRznSocial();
factura.getMtoImpVenta();
factura.getDetails().map((d) => d.getDescripcion());

// reimprimir
const html = new HtmlReport().render(factura, { system: { hash: '...' } });

InvoiceParserFacturas y boletas (UBL 2.0 y 2.1)

RetentionParser, PerceptionParserRetenciones y percepciones
