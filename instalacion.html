Instalación

El paquete es privado: se publica en GitHub Packages y solo pueden instalarlo las personas autorizadas. La configuración se hace una sola vez por computadora.

Requisitos

  • Node.js 18 o superior (usa fetch nativo y módulos ES: import).
  • Una cuenta de GitHub con acceso de lectura al paquete @jeanpierohc/sunat-manager.
  • Para emitir en producción: certificado digital y usuario SOL secundario. Para probar en beta no necesitas nada de SUNAT.

Pasos

  1. Pide acceso al paquete

    El dueño entra a github.com/users/JeanpieroHC/packages/npm/package/sunat-manager → Package settings → Manage access → Invite, y te asigna el rol Read. No necesitas acceso al código fuente.

  2. Crea un token de GitHub

    En github.com/settings/tokens → Generate new token (classic) → marca solo read:packages. Los tokens fine-grained no sirven para paquetes.

    Guárdalo como variable de entorno (no lo escribas dentro del proyecto):

    setx GITHUB_TOKEN "ghp_tuToken..."
# cierra y vuelve a abrir la terminal
    echo 'export GITHUB_TOKEN="ghp_tuToken..."' >> ~/.bashrc
source ~/.bashrc
    # Define GITHUB_TOKEN como secreto del entorno (GitHub Actions, Docker, etc.)
# En GitHub Actions del mismo dueño puedes usar ${{ secrets.GITHUB_TOKEN }}

  3. Crea un archivo .npmrc en tu proyecto

    @jeanpierohc:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}

    Este archivo sí puede subirse a tu repositorio: no contiene el token, solo la referencia a la variable.

  4. Instala

    npm install @jeanpierohc/sunat-manager

  5. Verifica

    import { montoEnLetras } from '@jeanpierohc/sunat-manager';
console.log(montoEnLetras(1180.5));
// SON MIL CIENTO OCHENTA CON 50/100 SOLES
    node prueba.mjs

Tu proyecto debe usar módulos ES. Agrega "type": "module" a tu package.json o usa archivos .mjs. Desde CommonJS puedes usar const lib = await import('@jeanpierohc/sunat-manager').

Problemas comunes

npm ERR! 401 Unauthorized o 403 Forbidden

El token no existe, venció, no tiene read:packages, o tu cuenta no tiene acceso al paquete. Verifica con echo %GITHUB_TOKEN% (Windows) o echo $GITHUB_TOKEN.

npm ERR! 404 Not Found

Falta el archivo .npmrc o la línea @jeanpierohc:registry=…: npm está buscando en el registro público.

SyntaxError: Cannot use import statement outside a module

Agrega "type": "module" a tu package.json o renombra el archivo a .mjs.
