📚 Conceptos de facturación electrónica

Si nunca has trabajado con SUNAT, empieza aquí. Explicamos, sin tecnicismos, todo lo que necesitas saber para entender qué hace la librería y por qué.

¿Qué es un comprobante electrónico?

Un comprobante de pago electrónico (CPE) es una factura, boleta o nota que, en lugar de imprimirse en papel con talonario, se genera como un archivo XML con un formato definido por SUNAT, se firma digitalmente (como una firma notarial, pero matemática) y se envía a SUNAT para que lo valide. Lo que le entregas a tu cliente (PDF o ticket) es solo una representación impresa de ese XML.

📄

El XML

Es el comprobante "real". Tiene un formato estándar internacional llamado UBL 2.1.

🔐

La firma

Garantiza que lo emitiste tú y que nadie lo modificó. Requiere un certificado digital.

📬

El CDR

La Constancia de Recepción que SUNAT devuelve: dice si el comprobante fue aceptado o rechazado.

🖨️

La representación impresa

El PDF o ticket que ve el cliente. Incluye un código QR y el "hash" de la firma.

💡

Serie y correlativo: el número de un comprobante tiene la forma SERIE-CORRELATIVO, por ejemplo F001-000123. La serie tiene 4 caracteres y el correlativo es un número que aumenta de 1 en 1 sin saltos. Tu sistema es responsable de llevar la cuenta.

El IGV y los tipos de afectación

El IGV (Impuesto General a las Ventas) es 18% en general. Pero no todo lo que vendes paga IGV: cada ítem indica su tipo de afectación (catálogo 07):

CódigoTipo¿Paga IGV?Ejemplo
10GravadoSí, 18%La mayoría de ventas
17IVAP4% IVAPArroz pilado
20ExoneradoNoProductos de la Amazonía, algunos alimentos
30InafectoNoLibros, servicios de educación
40ExportaciónNoVenta al exterior
11–16Gratuito gravado (retiro)IGV referencialBonificaciones, premios, muestras
21, 31–37Gratuito exonerado / inafectoNoRegalos de productos exonerados/inafectos

Otros tributos que la librería maneja: ISC (Impuesto Selectivo al Consumo: licores, cigarros, combustibles), ICBPER (impuesto a las bolsas plásticas, S/ 0.50 por bolsa) y percepciones/detracciones. Ver Cálculo de impuestos.

¿Valor unitario o precio unitario?

🏷️

Valor unitario

Sin impuestos. Ej.: S/ 100.00 (mto_valor_unitario)

💰

Precio unitario

Con impuestos. Ej.: S/ 118.00 (mto_precio_unitario)

Puedes indicar cualquiera de los dos; la calculadora obtiene el otro.

El CDR y los códigos de respuesta

El CDR trae un código que indica el resultado:

const result = await see.send(factura);
if (!result.isSuccess()) {
  // no hubo CDR: error de conexión, credenciales o excepción (códigos 0100-1999)
  console.log(result.getError().getCode(), result.getError().getMessage());
} else {
  const cdr = result.getCdrResponse();
  const code = parseInt(cdr.getCode(), 10);
  if (code === 0) console.log('ACEPTADO', cdr.getNotes());           // notas = observaciones
  else if (code >= 2000 && code <= 3999) console.log('RECHAZADO', cdr.getDescription());
}

Glosario

CPEComprobante de Pago Electrónico.
SEESistema de Emisión Electrónica. Usar esta librería es "SEE – Del contribuyente" (tú emites directo a SUNAT).
OSEOperador de Servicios Electrónicos: intermediario autorizado que valida por SUNAT. La librería puede enviar a un OSE cambiando el endpoint.
UBL 2.1Universal Business Language: estándar XML que SUNAT adoptó para los comprobantes.
CDRConstancia de Recepción: XML (dentro de un ZIP) con la respuesta de SUNAT.
Clave SOLUsuario y clave de SUNAT Operaciones en Línea. Para emitir se usa un usuario secundario con permisos de facturación.
Hash / resumenValor DigestValue de la firma; se imprime en el PDF.
CatálogosTablas de códigos oficiales de SUNAT (tipo de documento, afectación, unidades de medida, etc.).
GREGuía de Remisión Electrónica. Desde 2022 se envía por una API REST con credenciales propias.
