Preguntas frecuentes

¿Necesito Greenter o PHP instalado?

No. Es una implementación completa en JavaScript; solo requiere Node.js 18+.

¿Funciona con un OSE en lugar de SUNAT?

Sí: usa see.setService('https://url-del-ose/…/billService') con las credenciales que te dé el OSE.

¿Cómo manejo el correlativo?

Tu sistema debe guardar el último número por serie (por ejemplo en base de datos, con bloqueo o transacción) y usar el siguiente. Si un comprobante es rechazado, ese número queda inutilizado: emite el siguiente. Si hay error de conexión (sin CDR), reenvía el mismo número.

Se cortó la conexión y no sé si SUNAT lo recibió

Con credenciales de producción consulta su estado con ConsultCdrService.getStatusCdr: si existe, recuperas el CDR; si no, reenvíalo con el mismo número.

¿Qué debo guardar?

El XML firmado y el ZIP del CDR de cada comprobante. El PDF puede regenerarse en cualquier momento desde el XML (InvoiceParser + HtmlReport).

¿Por qué el ICBPER se cobra solo si pongo icbper: true?

El modelo SaleDetail (heredado de Greenter) trae un factor ICBPER por defecto de 0.30 en todos los ítems; si la calculadora lo usara, cobraría ICBPER a todo. Por eso las bolsas se marcan explícitamente.

¿Las fechas se guardan en UTC?

Los Date son instantes; al generar el XML se formatean en hora de Lima. Una venta del 15/01 a las 23:00 en Lima sale con fecha 15/01 aunque en UTC ya sea 16/01.

¿Puedo usarlo desde CommonJS (require)?

Usa const lib = await import('@jeanpierohc/sunat-manager') dentro de una función async.

Las pruebas en beta a veces fallan con HTTP 401 sin motivo

El entorno beta de SUNAT es inestable: hemos visto 401 intermitentes al enviar muchos comprobantes seguidos, y 401 persistentes con algún documento concreto (por ejemplo, datos de muestra con fechas antiguas) que se resuelven usando fechas y montos actuales.

Lista para pasar a producción

  1. Certificado digital real

    Convertido a PEM y guardado de forma segura. Revisa su fecha de vencimiento.

  2. Usuario SOL secundario

    Créalo en SUNAT Operaciones en Línea con permisos de emisión electrónica.

  3. Afiliación a SEE – Del contribuyente

    Regístrate como emisor electrónico y registra tu certificado en SUNAT Operaciones en Línea.

  4. Endpoints de producción

    SunatEndpoints.FE_PRODUCCION y, si aplica, RETENCION_PRODUCCION y la API de guías.

  5. Correlativos y almacenamiento

    Numeración sin saltos ni duplicados; guarda XML y CDR de cada comprobante.

  6. Manejo de errores

    Distingue error de conexión (reintentar) de rechazo (nuevo número) y registra las observaciones.

  7. Resúmenes y bajas

    Si usas resumen diario, consulta el ticket hasta obtener el CDR y guárdalo.
