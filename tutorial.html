🚀 Tutorial: tu primera factura

En unos 10 minutos vas a emitir una factura real en el entorno de pruebas de SUNAT, recibir su CDR y generar el ticket para el cliente. No necesitas certificado ni clave SOL reales.

🎯

Lo que lograrás: un script que envía una factura a SUNAT beta y guarda tres archivos: el XML firmado, el CDR (respuesta de SUNAT) y un ticket HTML de 80 mm.

Paso a paso

  1. Crea el proyecto

    mkdir mi-facturacion
cd mi-facturacion
npm init -y
npm pkg set type=module

    Configura el .npmrc e instala la librería como se explica en Instalación:

    npm install @jeanpierohc/sunat-manager

  2. Consigue un certificado de prueba

    SUNAT beta acepta cualquier certificado, incluso uno autofirmado. Créalo con OpenSSL (viene con Git para Windows):

    openssl req -x509 -newkey rsa:2048 -nodes -keyout llave.pem -out cert.pem -days 365 -subj "/CN=PRUEBA"

    Y únelos en un solo archivo certificado.pem (primero la llave, luego el certificado):

    Get-Content llave.pem, cert.pem | Set-Content certificado.pem
    cat llave.pem cert.pem > certificado.pem
    🔐

    En producción usarás tu certificado real (archivo .pfx). Ver Certificado digital para convertirlo a PEM.

  3. Escribe el script

    Crea emitir.js. Lee los comentarios: cada bloque es una etapa del proceso.

    import fs from 'node:fs';
import {
  See, SunatEndpoints, XmlErrorCodeProvider, DocumentMapper,
  HtmlReport, DefaultTemplateResolver, XmlUtils,
} from '@jeanpierohc/sunat-manager';

// ── 1. Datos de tu empresa (el emisor) ──────────────────────────────
const mapper = new DocumentMapper({
  company: {
    ruc: '20123456789',
    razon_social: 'MI EMPRESA S.A.C.',
    nombre_comercial: 'MI TIENDA',
    ubigeo: '150101', departamento: 'LIMA', provincia: 'LIMA', distrito: 'LIMA',
    direccion: 'AV. LIMA 123',
  },
});

// ── 2. La venta ─────────────────────────────────────────────────────
// Solo cantidades y precios: IGV, totales y leyendas se calculan solos.
const factura = mapper.invoice({
  serie: 'F001',
  correlativo: 1,                       // en tu sistema: el siguiente número libre
  client: {
    tipo_documento: '6',                // 6 = RUC, 1 = DNI
    numero_documento: '20000000001',
    razon_social: 'CLIENTE S.A.C.',
    direccion: 'AV. LOS OLIVOS 456',
  },
  detalles: [
    { codigo: 'P001', descripcion: 'MOUSE INALÁMBRICO', cantidad: 2, mto_precio_unitario: 59 },
    { codigo: 'S001', descripcion: 'INSTALACIÓN', cantidad: 1, mto_valor_unitario: 100, unidad: 'ZZ' },
  ],
});
console.log('Total:', factura.getMtoImpVenta());   // 236
console.log(factura.getLegends()[0].getValue());   // SON DOSCIENTOS TREINTA Y SEIS CON 00/100 SOLES

// ── 3. Configurar la conexión con SUNAT ─────────────────────────────
const see = new See();
see.setService(SunatEndpoints.FE_BETA);                          // pruebas
see.setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
see.setClaveSOL('20123456789', 'MODDATOS', 'moddatos');          // usuario de pruebas
see.setCodeProvider(new XmlErrorCodeProvider());                 // mensajes de error en español

// ── 4. Enviar ───────────────────────────────────────────────────────
const result = await see.send(factura);
const xml = see.getFactory().getLastXml();                       // XML firmado
fs.writeFileSync(`${factura.getName()}.xml`, xml);

if (!result.isSuccess()) {
  console.error('❌ Error', result.getError().getCode(), result.getError().getMessage());
  process.exit(1);
}

// ── 5. Leer la respuesta (CDR) ──────────────────────────────────────
const cdr = result.getCdrResponse();
fs.writeFileSync(`R-${factura.getName()}.zip`, result.getCdrZip());
console.log('✅', cdr.getDescription());
if (cdr.getNotes().length) console.log('Observaciones:', cdr.getNotes());

// ── 6. Ticket de 80 mm para el cliente ──────────────────────────────
const report = new HtmlReport();
report.setTemplate(new DefaultTemplateResolver().getTemplate(factura, '80mm'));
const html = report.render(factura, {
  system: { hash: new XmlUtils().getHashSign(xml) },
  user: { header: 'Telf: (01) 555-1234', footer: 'Gracias por su compra' },
});
fs.writeFileSync(`${factura.getName()}.html`, html);

  4. Ejecuta

    node emitir.js
    Total: 236
SON DOSCIENTOS TREINTA Y SEIS CON 00/100 SOLES
✅ La Factura numero F001-1, ha sido aceptada

    Abre el archivo .html en el navegador para ver el ticket. En la carpeta tendrás:

    20123456789-01-F001-1.xmlEl comprobante firmado. Debes guardarlo (es el documento legal).
    R-20123456789-01-F001-1.zipEl CDR de SUNAT. También debes guardarlo.
    20123456789-01-F001-1.htmlLa representación impresa (ticket) para el cliente.

Pasar a producción

Cuando todo funcione en beta, solo cambia la configuración:

see.setService(SunatEndpoints.FE_PRODUCCION);
see.setCertificate(fs.readFileSync('mi-certificado-real.pem', 'utf8'));
see.setClaveSOL('20XXXXXXXXX', 'USUARIOSOL', 'claveSol');   // usuario secundario con permiso de emisión
🛑

En producción, cada comprobante aceptado es real y tiene efectos tributarios. Nunca reutilices un correlativo y guarda siempre el XML y el CDR.
