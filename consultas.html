Consultas y CDR

SUNAT ofrece dos servicios de consulta. La librería soporta ambos y puede combinarlos automáticamente.

API REST de validez

¿Este comprobante existe y es válido? Funciona para comprobantes tuyos o de terceros (p. ej. facturas de proveedores). Requiere credenciales de API.

SOAP con clave SOL

Estado de tus propios comprobantes y descarga de su CDR. Requiere tu usuario SOL.

Validez de comprobantes (API REST)

Credenciales: SUNAT Operaciones en Línea → Empresa → Credenciales de API SUNAT → registra una aplicación y copia el client_id y el client_secret.

import { ConsultaCpe, CpeFilter } from '@jeanpierohc/sunat-manager';

const api = new ConsultaCpe(process.env.SUNAT_CLIENT_ID, process.env.SUNAT_CLIENT_SECRET);

const res = await api.consultar('20123456789',      // TU RUC (dueño de las credenciales)
  new CpeFilter({
    numRuc: '20000000001',          // RUC del emisor del comprobante consultado
    codComp: '01',                  // tipo de comprobante
    numeroSerie: 'F001',
    numero: 15,
    fechaEmision: '2024-01-15',     // o Date
    monto: 118,                     // opcional en boletas
  }));

res.isSuccess();                    // la consulta se realizó
res.isValido();                     // ACEPTADO o AUTORIZADO
res.getEstadoCpDescripcion();       // 'ACEPTADO'
res.getEstadoRucDescripcion();      // 'ACTIVO'
res.getCondDomiRucDescripcion();    // 'HABIDO'

Consulta en lote

const resultados = await api.consultarVarios('20123456789', filtros, { delay: 300 });
for (const { filter, result, error } of resultados) {
  console.log(filter.numeroSerie, filter.numero, error ? error.message : result.getEstadoCpDescripcion());
}

El token OAuth2 se obtiene una vez y se renueva solo. Si tienes varios procesos, comparte el token con new ConsultaCpe(id, secret, { tokenStore: { get, set } }) (por ejemplo, sobre Redis).

Estado y CDR de tus comprobantes (SOAP)

import { SoapClient, ConsultCdrService, SunatEndpoints } from '@jeanpierohc/sunat-manager';

const client = new SoapClient();
client.setService(SunatEndpoints.FE_CONSULTA_CDR);
client.setCredentials('20123456789USUARIOSOL', 'claveSol');     // RUC + usuario, clave

const service = new ConsultCdrService().setClient(client);

const estado = await service.getStatus('20123456789', '01', 'F001', 15);
console.log(estado.getCode(), estado.getMessage());

const conCdr = await service.getStatusCdr('20123456789', '01', 'F001', 15);
if (conCdr.getCdrZip()) fs.writeFileSync('R-F001-15.zip', conCdr.getCdrZip());

Este servicio solo existe en producción y necesita credenciales SOL reales (no funciona con MODDATOS).

Lo mejor de ambos: ConsultaCpeService

Intenta primero la API REST y, si falla o no hay credenciales, usa SOAP con clave SOL:

import { ConsultaCpeService } from '@jeanpierohc/sunat-manager';

const service = new ConsultaCpeService({
  api: { clientId: process.env.SUNAT_CLIENT_ID, clientSecret: process.env.SUNAT_CLIENT_SECRET },
  sol: { ruc: '20123456789', user: 'USUARIOSOL', password: 'claveSol' },
});

const r = await service.consultar(factura);   // un Invoice/Note o { ruc, tipo, serie, numero, fechaEmision, monto }
// { success, metodo: 'api' | 'sol', estado, codigo, mensaje, result, apiError? }

const conCdr = await service.consultar(factura, { cdr: true });   // va directo a SOAP y descarga el CDR

Leer un CDR

Cada respuesta exitosa trae el CDR ya interpretado:

const cdr = result.getCdrResponse();
cdr.getId();           // 'F001-15'
cdr.getCode();         // '0'
cdr.getDescription();  // 'La Factura numero F001-15, ha sido aceptada'
cdr.getNotes();        // observaciones (códigos 4000+)
cdr.isAccepted();      // true
result.getCdrZip();    // Buffer con el ZIP original (guárdalo)

Para leer un CDR guardado en disco:

import { ZipFly, DomCdrReader } from '@jeanpierohc/sunat-manager';

const xml = new ZipFly().decompress(fs.readFileSync('R-20123456789-01-F001-15.zip'))
  .find((f) => f.filename.endsWith('.xml')).content;
const cdr = new DomCdrReader().getCdrResponse(xml);
