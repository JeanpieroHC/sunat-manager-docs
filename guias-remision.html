🚚 Guías de remisión electrónicas (GRE)

Desde 2022 las guías se envían por una API REST de SUNAT (no por SOAP como las facturas). La fachada Api se encarga del token OAuth2, el envío y la consulta del ticket.

Credenciales necesarias

Además del certificado y la clave SOL, necesitas credenciales de API: en SUNAT Operaciones en Línea → Empresa → Credenciales de API SUNAT registras una aplicación y obtienes un client_id y un client_secret.

Ejemplo completo

import fs from 'node:fs';
import { Api, DocumentMapper } from '@jeanpierohc/sunat-manager';

const api = new Api();   // producción por defecto. Pruebas: new Api({ auth: 'https://…', cpe: 'https://…' })
api.setApiCredentials(process.env.SUNAT_CLIENT_ID, process.env.SUNAT_CLIENT_SECRET)
   .setClaveSOL('20123456789', 'USUARIOSOL', 'claveSol')
   .setCertificate(fs.readFileSync('certificado.pem', 'utf8'));

const mapper = new DocumentMapper({ company: { ruc: '20123456789', razon_social: 'MI EMPRESA S.A.C.',
  ubigeo: '150101', departamento: 'LIMA', provincia: 'LIMA', distrito: 'LIMA', direccion: 'AV. LIMA 123' } });

const guia = mapper.despatch({
  serie: 'T001', correlativo: 1,
  destinatario: { tipo_documento: '6', numero_documento: '20000000002', razon_social: 'DESTINO S.A.C.' },
  cod_traslado: '01',            // 01 venta, 04 entre establecimientos… (catálogo 20)
  mod_traslado: '02',            // 01 transporte público, 02 privado (catálogo 18)
  fec_traslado: '2024-01-16',
  peso_total: 12.5, und_peso_total: 'KGM', num_bultos: 2,
  partida: { ubigeo: '150101', direccion: 'AV. LIMA 123' },
  llegada: { ubigeo: '150203', direccion: 'AV. ARRIBA 456' },
  conductor: { tipo_doc: '1', num_doc: '44556677', licencia: 'Q44556677', nombres: 'JUAN', apellidos: 'PÉREZ' },
  vehiculo_placa: 'ABC123',
  detalles: [{ codigo: 'P001', descripcion: 'PRODUCTO', cantidad: 2, unidad: 'NIU' }],
});

const res = await api.send(guia);
if (!res.isSuccess()) throw new Error(res.getError().getMessage());

// consultar el ticket hasta que SUNAT termine de procesar
let status;
do {
  await new Promise((r) => setTimeout(r, 2000));
  status = await api.getStatus(res.getTicket());
} while (status.getCode() === '98');           // 98 = en proceso

console.log(status.isSuccess() ? status.getCdrResponse().getDescription() : status.getError().getMessage());

Transporte público vs privado

Usas tus propios vehículos: se informan conductor(es) y placa(s).

{
  mod_traslado: '02',
  conductores: [
    { num_doc: '44556677', licencia: 'Q44556677', nombres: 'JUAN', apellidos: 'PÉREZ' },   // Principal
    { num_doc: '11223344', licencia: 'Q11223344', nombres: 'ANA', apellidos: 'RAMOS' },    // Secundario
  ],
  vehiculo_placa: 'ABC123',
  vehiculos_secundarios: [{ placa: 'XYZ999' }],     // carreta, remolque…
}

Contratas una empresa de transporte: se informa el transportista.

{
  mod_traslado: '01',
  transportista: { tipo_doc: '6', num_doc: '20999999999', razon_social: 'TRANSPORTES S.A.C.', nro_mtc: 'MTC123' },
}

Traslado entre locales de la misma empresa: el RUC del emisor se coloca automáticamente en partida y llegada; indica el código de cada local.

{
  cod_traslado: '04',
  partida: { ubigeo: '150101', direccion: 'ALMACÉN CENTRAL', cod_local: '0001' },
  llegada: { ubigeo: '150203', direccion: 'TIENDA NORTE', cod_local: '0002' },
}

Campos de la guía

CampoDescripción
serie, correlativo, fecha_emisionNumeración y fecha
tipo_documento09 remitente (defecto) o 31 transportista
version2022 (defecto, formato vigente)
destinatarioMismo formato que el cliente
cod_traslado, des_trasladoMotivo (catálogo 20)
mod_trasladoModalidad (catálogo 18)
fec_trasladoFecha de inicio del traslado
peso_total, und_peso_total (KGM), num_bultosPeso y bultos
partida, llegada{ ubigeo, direccion, ruc?, cod_local? } (o partida_ubigeo, partida_direccion…)
conductor / conductores{ tipo_doc, num_doc, licencia, nombres, apellidos, tipo? }
vehiculo_placa, vehiculos_secundariosPlacas
transportista{ tipo_doc, num_doc, razon_social, nro_mtc }
indicadoresEj. ['SUNAT_Envio_IndicadorTrasladoVehiculoM1L']
documentos_relacionados[{ tipo, tipo_desc, nro, emisor }]
observacionesTexto libre
detalles[{ codigo, descripcion, cantidad, unidad, codigo_sunat? }]
💡

El token se guarda en memoria y se reutiliza hasta 10 minutos antes de vencer. Si tienes varios procesos, puedes pasar tu propio almacén (Redis, base de datos) a ApiFactory.
