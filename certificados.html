Certificado digital y firma

Cada comprobante debe ir firmado con el certificado digital de tu empresa. La librería usa el formato PEM (texto) y te ayuda a convertir tu certificado .pfx / .p12.

¿Qué es y dónde lo consigo?

Es un archivo que contiene una llave privada (secreta, solo tuya) y un certificado (público, dice quién eres). Se compra a una entidad certificadora acreditada o, para empresas que califican, SUNAT entrega uno gratuito. Normalmente lo recibes como .pfx o .p12 con una contraseña.

Convertir PFX a PEM

import fs from 'node:fs';
import { X509Certificate, X509ContentType } from '@jeanpierohc/sunat-manager';

const cert = X509Certificate.fromFile('mi-certificado.pfx', 'contraseña');

fs.writeFileSync('certificado.pem', cert.export(X509ContentType.PEM));   // llave + certificado (para firmar)
fs.writeFileSync('publico.cer', cert.export(X509ContentType.CER));       // solo el certificado público

console.log(cert.getInfo());
// { subject: { CN: '20123456789 MI EMPRESA', … }, issuer: {…}, serialNumber, validFrom, validTo }

Soporta los formatos usados en Perú: certificados modernos (AES-256), antiguos (3DES / RC2-40) y contraseñas con tildes o ñ. Si la contraseña es incorrecta lanza "Contraseña del certificado incorrecta".

Protege el archivo PEM: contiene tu llave privada sin contraseña. No lo subas a Git, guárdalo con permisos restringidos o en un gestor de secretos, y cárgalo en tiempo de ejecución.

Revisar el vencimiento

const { validTo } = X509Certificate.fromFile('mi-certificado.pfx', 'contraseña').getInfo();
const dias = Math.floor((validTo - Date.now()) / 86400000);
if (dias < 30) console.warn(`El certificado vence en ${dias} días`);

Firmar y verificar

See firma automáticamente. Si necesitas firmar un XML por tu cuenta:

import { SignedXml } from '@jeanpierohc/sunat-manager';

const signer = new SignedXml().setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
const firmado = signer.signXml(xmlSinFirmar);    // agrega ds:Signature en ext:ExtensionContent
signer.verify(firmado);                          // true si la firma es válida

Certificado para pruebas

En beta cualquier certificado sirve, incluso autofirmado:

openssl req -x509 -newkey rsa:2048 -nodes -keyout llave.pem -out cert.pem -days 365 -subj "/CN=PRUEBA"
cat llave.pem cert.pem > certificado.pem
