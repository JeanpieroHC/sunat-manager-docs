Comprobantes desde JSON

DocumentMapper convierte un objeto JSON simple (claves en español, snake_case) en el modelo que la librería envía a SUNAT. Es ideal cuando la venta llega desde tu frontend, otra API o la base de datos.

Uso básico

import { DocumentMapper } from '@jeanpierohc/sunat-manager';

const mapper = new DocumentMapper({
  company: { ruc: '20123456789', razon_social: 'MI EMPRESA S.A.C.', ubigeo: '150101',
             departamento: 'LIMA', provincia: 'LIMA', distrito: 'LIMA', direccion: 'AV. LIMA 123' },
  // calcular: 'auto' (por defecto) | true | false
  // calculator: { igv: 18, icbper: 0.5 }
});

const factura = mapper.invoice(req.body);   // también: boleta, creditNote, debitNote, summary, voided, despatch, retention
const doc = mapper.create(req.body);        // elige según tipo_documento (01, 03, 07, 08, 09, 20) o "tipo"

¿Cuándo calcula?

Opción calcularComportamiento
'auto' (defecto)Si el JSON no trae mto_imp_venta, calcula todo. Si lo trae, usa tus montos tal cual.
trueSiempre recalcula (ignora los montos que envíes, excepto los de entrada de cada ítem).
falseNunca calcula; solo agrega la leyenda del monto en letras si falta.

Campos del comprobante

CampoDefectoDescripción
serie, correlativo—Numeración
fecha_emisionahoraYYYY-MM-DD, ISO con hora, o Date. Se interpreta en hora de Lima.
fecha_vencimiento—Fecha de vencimiento
monedaPENCódigo ISO 4217
tipo_operacion0101Catálogo 51: 0101 venta interna, 0200 exportación, 1001 detracción, 2001 percepción
forma_pago_tipoContadoContado o Credito
cuotas / forma_pago_cuotas—[{ fecha_pago, monto?, moneda? }]
descuentos—Globales: [{ cod_tipo: '02', factor: 0.05 }] o { cod_tipo: '03', monto: 5 }
cargos—Globales: [{ cod_tipo: '50', monto: 10 }]
anticipos—[{ nro_doc_rel: 'F001-10', total: 118, tipo_doc_rel: '02' }]
redondeo—Ajuste por redondeo (positivo o negativo)
detraccion—{ codigo_bien_servicio, cuenta_banco, porcentaje, codigo_medio_pago?, monto? }
percepcion—{ cod_regimen, tasa, monto_base?, monto?, monto_total? }
retencion—{ tasa, monto_base, monto } (cargo de retención del IGV, código 62)
guias—[{ tipo_doc, nro_doc }]
observacion, orden_compra—Datos adicionales
leyendasautomáticas[{ code, value }]

CampoDefectoDescripción

cantidad—Admite decimales
mto_valor_unitario—Precio sin impuestos…

tip_sis_isc + porcentaje_isc—ISC: sistema (01 al valor) y tasa

descuentos, cargos—Del ítem: [{ cod_tipo: '00', factor: 0.1 }]

Usarlo en una API REST

import express from 'express';
import fs from 'node:fs';
import { See, SunatEndpoints, DocumentMapper } from '@jeanpierohc/sunat-manager';

const app = express();
app.use(express.json());

const mapper = new DocumentMapper({ company: JSON.parse(fs.readFileSync('empresa.json', 'utf8')) });
const see = new See();
see.setService(SunatEndpoints.FE_BETA);
see.setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
see.setClaveSOL('20123456789', 'MODDATOS', 'moddatos');

app.post('/comprobantes', async (req, res) => {
  try {
    const doc = mapper.create(req.body);
    const result = await see.send(doc);
    if (!result.isSuccess()) {
      return res.status(422).json({ error: result.getError().getCode(), mensaje: result.getError().getMessage() });
    }
    const cdr = result.getCdrResponse();
    res.json({
      nombre: doc.getName(),
      total: doc.getMtoImpVenta(),
      codigo: cdr.getCode(),
      descripcion: cdr.getDescription(),
      observaciones: cdr.getNotes(),
      xml: see.getFactory().getLastXml(),
      cdr: result.getCdrZip().toString('base64'),
    });
  } catch (e) {
    res.status(400).json({ error: e.message });   // datos inválidos
  }
});

app.listen(3000);

Las claves aceptadas son las mismas que usaba el proyecto Laravel /API, así que puedes reutilizar sus colecciones de Postman.
