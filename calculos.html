🧮 Cálculo de impuestos y totales

SUNAT rechaza un comprobante si sus montos no cuadran al céntimo. SaleCalculator hace esos cálculos por ti: indicas cantidades y precios, y completa el IGV, los totales y las leyendas.

Pruébalo aquí

Cambia cantidades, precios y tipos de afectación y mira cómo se recalcula todo. Abajo verás el JSON que enviarías a DocumentMapper para obtener el mismo resultado.

ℹ️

Esta calculadora es una demostración simplificada que corre en tu navegador. La librería además maneja ISC, descuentos, cargos, anticipos, percepción, detracción y cuotas.

Cómo se forma el total

Uso directo de SaleCalculator

Si construyes los modelos tú mismo (sin JSON), usa la calculadora así:

import { Invoice, SaleDetail, SaleCalculator } from '@jeanpierohc/sunat-manager';

const invoice = new Invoice()
  .setTipoMoneda('PEN')
  .setDetails([
    new SaleDetail().setDescripcion('PRODUCTO').setUnidad('NIU').setCantidad(2).setMtoValorUnitario(50),
    new SaleDetail().setDescripcion('BOLSA').setUnidad('NIU').setCantidad(1).setMtoValorUnitario(0.1).setIcbper(true),
  ]);

new SaleCalculator().calculate(invoice);
invoice.getMtoOperGravadas(); // 100.10
invoice.getMtoIGV();          // 18.02
invoice.getIcbper();          // 0.50
invoice.getMtoImpVenta();     // 118.62
invoice.getLegends()[0].getValue(); // SON CIENTO DIECIOCHO CON 62/100 SOLES

Casos soportados

Todos estos casos se enviaron a SUNAT beta y fueron aceptados sin observaciones.

Gravado, exonerado, inafecto y gratuito

detalles: [
  { descripcion: 'GRAVADO',    cantidad: 2, mto_valor_unitario: 50 },                    // IGV 18%
  { descripcion: 'EXONERADO',  cantidad: 1, mto_valor_unitario: 20, tip_afe_igv: '20' },
  { descripcion: 'INAFECTO',   cantidad: 1, mto_valor_unitario: 15, tip_afe_igv: '30' },
  { descripcion: 'BONIFICACIÓN', cantidad: 2, mto_valor_gratuito: 10, tip_afe_igv: '13' }, // IGV referencial, no se cobra
]
// gravadas 100 · exoneradas 20 · inafectas 15 · gratuitas 20 · IGV 18 · TOTAL 153.00
// + leyenda 1002 "TRANSFERENCIA GRATUITA…"

Precio con IGV incluido

Muy común en tiendas: el precio de etiqueta ya incluye IGV. Usa mto_precio_unitario; el valor sin IGV se obtiene dividiendo entre 1.18 y el precio que informaste se respeta.

{ descripcion: 'GASEOSA', cantidad: 7, mto_precio_unitario: 12.90 }
// valor unitario 10.9322… · valor venta 76.53 · IGV 13.78 · total 90.31

ISC e ICBPER

{ descripcion: 'LICOR', cantidad: 2, mto_valor_unitario: 100, tip_sis_isc: '01', porcentaje_isc: 20 },
// ISC = 200 × 20% = 40 · base IGV = 200 + 40 = 240 · IGV = 43.20
{ descripcion: 'BOLSA', cantidad: 3, mto_valor_unitario: 0.10, icbper: true },
// ICBPER = 3 × 0.50 = 1.50
⚠️

Para ICBPER marca el ítem con icbper: true (o setIcbper(true)). El modelo hereda de greenter un factor por defecto de 0.30, que se ignora.

mapper.invoice({
  ...,
  redondeo: -0.03,
  descuentos: [{ cod_tipo: '02', factor: 0.05 }, { cod_tipo: '03', monto: 5 }],
  detalles: [
    { descripcion: 'A', cantidad: 2, mto_valor_unitario: 100, descuentos: [{ cod_tipo: '00', factor: 0.1 }] },
    { descripcion: 'B', cantidad: 1, mto_valor_unitario: 50.5 },
  ],
});
// ítem A: 200 − 10% = 180 · gravadas 230.50 − 5% = 218.97 · IGV 39.41
// total = 258.38 − 5.00 (desc. 03) − 0.03 (redondeo) = 253.35

Exportación e IVAP

mapper.invoice({ tipo_operacion: '0200', client: { tipo_documento: '0', numero_documento: '-', razon_social: 'FOREIGN CO' },
  detalles: [{ descripcion: 'CAFÉ', cantidad: 10, mto_valor_unitario: 25, tip_afe_igv: '40' }] });   // total 250, sin IGV

mapper.invoice({ detalles: [{ descripcion: 'ARROZ PILADO', cantidad: 10, mto_valor_unitario: 3.5, tip_afe_igv: '17' }] });
// IVAP 4% = 1.40 · total 36.40 · leyenda 2007. Una factura con IVAP solo puede tener ítems IVAP.

Crédito, cuotas y detracción

mapper.invoice({
  tipo_operacion: '1001', forma_pago_tipo: 'Credito',
  detraccion: { codigo_bien_servicio: '037', cuenta_banco: '00-123', porcentaje: 12 },
  cuotas: [{ fecha_pago: '2024-02-15', monto: 500 }, { fecha_pago: '2024-03-15' }, { fecha_pago: '2024-04-15' }],
  detalles: [{ descripcion: 'SERVICIO', unidad: 'ZZ', cantidad: 1, mto_valor_unitario: 1000 }],
});
// total 1180 · detracción 12% = 141.60 · pendiente de pago 1038.40
// cuotas: 500 + 269.20 + 269.20 (el saldo se reparte entre las cuotas sin monto)

Anticipos

Cuando el cliente pagó un adelanto con otra factura, informa el anticipo; se genera el descuento 04 y el IGV se calcula sobre la diferencia:

mapper.invoice({ anticipos: [{ nro_doc_rel: 'F001-10', total: 50 }],
  detalles: [{ descripcion: 'SALDO', cantidad: 1, mto_valor_unitario: 200 }] });
// valor de venta 200 · base IGV 157.63 · IGV 28.37 · total 236 − anticipo 50 = 186

Percepción

mapper.invoice({ tipo_operacion: '2001', percepcion: { cod_regimen: '51', tasa: 2 }, detalles: [...] });
// total 177 → percepción 2% = 3.54 → total a cobrar 180.54

Monto en letras

La leyenda 1000 ("SON … CON xx/100 SOLES") es obligatoria. Pruébalo:

import { montoEnLetras } from '@jeanpierohc/sunat-manager';
montoEnLetras(21180.5);                      // SON VEINTIÚN MIL CIENTO OCHENTA CON 50/100 SOLES
montoEnLetras(1000000, 'USD');               // SON UN MILLÓN CON 00/100 DÓLARES AMERICANOS
montoEnLetras(15, 'PEN', { prefix: '' });    // QUINCE CON 00/100 SOLES
