Referencia de la API

Clases y métodos principales. Los modelos siguen la convención de Greenter: cada propiedad tiene getX() y setX(valor), y los set se pueden encadenar.

Asíncrono: todo lo que habla con SUNAT o genera PDF devuelve una Promise (usa await): See.send, See.getStatus, Api.*, ConsultaCpe.*, PdfReport.render. Generar XML, firmar, calcular, validar y leer XML es síncrono.

Fechas

Las fechas son objetos Date y se formatean en hora de Lima (America/Lima). Para crear una fecha sin hora usa toDate('2024-01-15') (exportado desde …/core) o pasa el texto directamente a DocumentMapper.
