Facturación electrónica SUNAT desde Node.js

@jeanpierohc/sunat-manager es una librería que hace todo el trabajo pesado de la facturación electrónica en Perú: arma el XML oficial, lo firma con tu certificado digital, lo envía a SUNAT, interpreta la respuesta y genera el PDF o ticket para tu cliente.

¿Cómo funciona?

Tu aplicación solo describe la venta (cliente, productos, cantidades y precios). La librería se encarga del resto. Observa el recorrido de un comprobante:

El documento recorre todo el proceso en milisegundos. Tú solo escribes el paso 1.

En 30 segundos

import fs from 'node:fs';
import { See, SunatEndpoints, DocumentMapper } from '@jeanpierohc/sunat-manager';

// 1. Tus datos de empresa (una sola vez)
const mapper = new DocumentMapper({
  company: { ruc: '20123456789', razon_social: 'MI EMPRESA S.A.C.', ubigeo: '150101',
             departamento: 'LIMA', provincia: 'LIMA', distrito: 'LIMA', direccion: 'AV. LIMA 123' },
});

// 2. La venta: los impuestos y totales se calculan solos
const factura = mapper.invoice({
  serie: 'F001', correlativo: 1,
  client: { tipo_documento: '6', numero_documento: '20000000001', razon_social: 'CLIENTE S.A.C.' },
  detalles: [{ descripcion: 'LAPTOP', cantidad: 1, mto_precio_unitario: 2360 }],
});

// 3. Enviar a SUNAT
const see = new See();
see.setService(SunatEndpoints.FE_BETA);                         // entorno de pruebas
see.setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
see.setClaveSOL('20123456789', 'MODDATOS', 'moddatos');

const result = await see.send(factura);
console.log(result.getCdrResponse().getDescription());
// → "La Factura numero F001-1, ha sido aceptada"

¿Qué puedes hacer?

🧾

Emitir todos los comprobantes

Facturas, boletas, notas de crédito/débito, resúmenes diarios, bajas, retenciones y percepciones.
🧮

Calcular impuestos solo

IGV, ISC, ICBPER, IVAP, gratuitas, exportación, descuentos, anticipos, detracción y cuotas.
🧩

Crear desde JSON

Recibe la venta de tu API o frontend como JSON y conviértela en comprobante con una línea.
🚚

Guías de remisión

Envío por la nueva API REST de SUNAT (GRE 2022), con token automático.
🖨️

PDF y tickets

Representación impresa en A4, A5 o ticket de 80/58/50 mm, con código QR.
🔎

Consultar comprobantes

Verifica si un comprobante es válido y recupera CDRs.
✅

Validar antes de enviar

Detecta errores antes de que SUNAT los rechace y lee XML existentes.
🔐

Certificados

Convierte tu .pfx/.p12 a PEM y firma documentos.
