Todos los documentos

Ejemplos listos para copiar de cada tipo de comprobante. Todos suponen esta configuración inicial:

import fs from 'node:fs';
import { See, SunatEndpoints, XmlErrorCodeProvider, DocumentMapper } from '@jeanpierohc/sunat-manager';

export const mapper = new DocumentMapper({ company: {
  ruc: '20123456789', razon_social: 'MI EMPRESA S.A.C.', ubigeo: '150101',
  departamento: 'LIMA', provincia: 'LIMA', distrito: 'LIMA', direccion: 'AV. LIMA 123',
} });

export const see = new See();
see.setService(SunatEndpoints.FE_BETA);
see.setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
see.setClaveSOL('20123456789', 'MODDATOS', 'moddatos');
see.setCodeProvider(new XmlErrorCodeProvider());

¿Qué documento necesito?

Factura

const factura = mapper.invoice({
  serie: 'F001', correlativo: 1,
  client: { tipo_documento: '6', numero_documento: '20000000001', razon_social: 'CLIENTE S.A.C.' },
  detalles: [{ descripcion: 'PRODUCTO', cantidad: 1, mto_valor_unitario: 100 }],
});
const result = await see.send(factura);

Boleta

const boleta = mapper.boleta({
  serie: 'B001', correlativo: 1,
  client: { tipo_documento: '1', numero_documento: '45678912', razon_social: 'JUAN PÉREZ' },
  // cliente sin documento (ventas menores): { tipo_documento: '0', numero_documento: '-', razon_social: 'CLIENTES VARIOS' }
  detalles: [{ descripcion: 'PRODUCTO', cantidad: 1, mto_precio_unitario: 25 }],
});
const result = await see.send(boleta);   // envío individual (también puedes usar resumen diario)

Nota de crédito

Corrige o anula una factura o boleta ya aceptada. Motivos frecuentes (catálogo 09): 01 anulación de la operación, 04 descuento global, 06 devolución total, 07 devolución por ítem, 13 ajuste de montos/fechas de pago.

const nc = mapper.creditNote({
  serie: 'FC01', correlativo: 1,        // serie F… para facturas, B… para boletas
  tipo_doc_afectado: '01', num_doc_afectado: 'F001-1',
  cod_motivo: '07', des_motivo: 'DEVOLUCIÓN DE PRODUCTO DAÑADO',
  client: { tipo_documento: '6', numero_documento: '20000000001', razon_social: 'CLIENTE S.A.C.' },
  detalles: [{ descripcion: 'PRODUCTO', cantidad: 1, mto_valor_unitario: 100 }],
});
await see.send(nc);

Nota de débito

Aumenta el valor de un comprobante. Motivos (catálogo 10): 01 intereses por mora, 02 aumento en el valor, 03 penalidades.

const nd = mapper.debitNote({

await see.send(nd);

Resumen diario de boletas

Agrupa las boletas (y sus notas) de un día en un solo envío. También se usa para anular boletas (estado 3). La respuesta es un ticket:

const resumen = mapper.summary({
  correlativo: '001',                   // único por día
  fecha_referencia: '2024-01-15',       // fecha de las boletas
  detalles: [
    { tipo_documento: '03', serie_numero: 'B001-1', estado: '1', cliente_tipo: '1', cliente_numero: '45678912',
      total: 118, mto_oper_gravadas: 100, mto_igv: 18 },
    { tipo_documento: '03', serie_numero: 'B001-2', estado: '3', cliente_tipo: '1', cliente_numero: '45678912',
      total: 59, mto_oper_gravadas: 50, mto_igv: 9 },                       // anulación
  ],
});
const res = await see.send(resumen);
const ticket = res.getTicket();

// SUNAT procesa en segundo plano: consulta el ticket después de unos segundos
await new Promise((r) => setTimeout(r, 3000));
const status = await see.getStatus(ticket);
console.log(status.getCode(), status.getCdrResponse()?.getDescription());   // '0' = aceptado, '98' = en proceso
Estado del ítemSignificado
1Adicionar
2Modificar
3Anular

Comunicación de baja

Anula facturas (y sus notas) ya aceptadas. También responde con ticket:

const baja = mapper.voided({
  correlativo: '001',
  fecha_referencia: '2024-01-15',       // fecha de emisión de la factura
  detalles: [{ tipo_documento: '01', serie: 'F001', correlativo: 1, motivo: 'ERROR EN LA DESCRIPCIÓN' }],
});
const res = await see.send(baja);
const status = await see.getStatus(res.getTicket());

Retención

Los comprobantes de retención y percepción usan otro endpoint:

const seeRet = new See();
seeRet.setService(SunatEndpoints.RETENCION_BETA);     // producción: RETENCION_PRODUCCION
seeRet.setCertificate(fs.readFileSync('certificado.pem', 'utf8'));
seeRet.setClaveSOL('20123456789', 'MODDATOS', 'moddatos');

const retencion = mapper.retention({
  serie: 'R001', correlativo: 1,
  proveedor: { tipo_documento: '6', numero_documento: '20000000001', razon_social: 'PROVEEDOR S.A.C.' },
  regimen: '01', tasa: 3, imp_retenido: 3, imp_pagado: 97,
  detalles: [{
    tipo_doc: '01', num_doc: 'F001-1', fecha_emision: '2024-01-10', fecha_retencion: '2024-01-15',
    moneda: 'PEN', imp_total: 100, imp_pagar: 97, imp_retenido: 3,
    pagos: [{ moneda: 'PEN', fecha: '2024-01-15', importe: 100 }],
    tipo_cambio: { fecha: '2024-01-15', factor: 1, moneda_obj: 'PEN', moneda_ref: 'PEN' },
  }],
});
await seeRet.send(retencion);

Percepción

El comprobante de percepción se construye con los modelos (no tiene atajo JSON):

import { Perception, PerceptionDetail, Payment, Exchange, Client } from '@jeanpierohc/sunat-manager';

const percepcion = new Perception()
  .setSerie('P001').setCorrelativo('1').setFechaEmision(new Date())
  .setCompany(mapper.company)
  .setProveedor(new Client().setTipoDoc('6').setNumDoc('20000000001').setRznSocial('CLIENTE S.A.C.'))
  .setRegimen('01').setTasa(2).setImpPercibido(2).setImpCobrado(102)
  .setDetails([new PerceptionDetail()
    .setTipoDoc('01').setNumDoc('F001-1').setFechaEmision(new Date()).setFechaPercepcion(new Date())
    .setMoneda('PEN').setImpTotal(100).setImpCobrar(102).setImpPercibido(2)
    .setCobros([new Payment().setMoneda('PEN').setFecha(new Date()).setImporte(100)])
    .setTipoCambio(new Exchange().setFecha(new Date()).setFactor(1).setMonedaObj('PEN').setMonedaRef('PEN'))]);
await seeRet.send(percepcion);

Construir con los modelos (estilo Greenter)

Todo lo anterior también se puede hacer creando los objetos a mano, igual que en Greenter PHP. Útil si migras código existente:

import { Invoice, SaleDetail, Company, Address, Client, FormaPagoContado, SaleCalculator } from '@jeanpierohc/sunat-manager';

const invoice = new Invoice()
  .setUblVersion('2.1').setTipoOperacion('0101').setTipoDoc('01')
  .setSerie('F001').setCorrelativo('1').setFechaEmision(new Date())
  .setFormaPago(new FormaPagoContado()).setTipoMoneda('PEN')
  .setCompany(new Company().setRuc('20123456789').setRazonSocial('MI EMPRESA S.A.C.')
    .setAddress(new Address().setUbigueo('150101').setDepartamento('LIMA').setProvincia('LIMA')
      .setDistrito('LIMA').setDireccion('AV. LIMA 123')))
  .setClient(new Client().setTipoDoc('6').setNumDoc('20000000001').setRznSocial('CLIENTE S.A.C.'))
  .setDetails([new SaleDetail().setCodProducto('P001').setUnidad('NIU').setDescripcion('PRODUCTO')
    .setCantidad(2).setMtoValorUnitario(50).setTipAfeIgv('10')]);

new SaleCalculator().calculate(invoice);   // o llena tú cada monto: setMtoIGV, setMtoImpVenta…
await see.send(invoice);
